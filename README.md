# 找羊加热台 Pro 极速版固件 (基于 GD32E230)

本项目是一个基于 GD32E230C8T6 的小型智能加热台/回流焊平台，是对开源社区经典的“找羊加热台/QF-HP”重新设计并编写的**极限优化版固件**。

本固件在 **UI流畅度、温度控制算法（防过冲）、人机交互逻辑及安全性** 上进行了断代式的升级，致力于打造使用体验最棒的开源加热台。使用 PlatformIO 环境开发，C 语言编写，核心逻辑均附带 100% 覆盖率的本地单元测试。

> 📌 **硬件开源参考**：本项目硬件基于立创开源平台经典找羊加热台方案 [sheep_finder/pcb-heng-wen-jia-re-tai](https://oshwhub.com/sheep_finder/pcb-heng-wen-jia-re-tai)。

## 🌟 核心固件升级亮点

#### 1. 🚀 硬件 SPI 驱动重构，UI 丝滑如飞
原版固件及市面多数改版通常使用“软件模拟 SPI”驱动彩色屏幕，会导致旋转旋钮时严重卡顿、漏步。
本固件将 ST7735 屏幕与 MAX6675 测温模块完美接入 GD32 的 **原生硬件 SPI0** 控制器。结合动态频率切换技术（测温 2.25MHz / 刷屏 18MHz），释放了 90% 的 CPU 算力，让**旋钮响应做到 0 延迟，界面刷新丝滑流畅**。

#### 2. 🛡️ 智能防过冲热惯性算法
本固件在底层实现了 **3秒前馈预测滑行算法 (Lookahead Coasting) + EMA 一阶低通滤波**。系统会平滑计算升温速率，提前切断加热器进行断电滑行。实测升温极其平稳，彻底告别目标温度上下剧烈波动的现象。

#### 3. 🚦 全局安全温度指示
不论处于主菜单还是设置界面，屏幕右上角会**全局实时显示当前加热板温度**，并带有直观的**变色安全警告**，防止烫伤：
*   🟢 **绿色 (< 45℃)**：安全状态，可放心触摸。
*   🟡 **黄色 (45℃ - 60℃)**：余热警告，微烫需注意。
*   🔴 **红色 (> 60℃)**：危险状态，严禁触摸！
*   ❌ **红色 "----"**：热电偶未接或故障报警。

#### 4. 🎶 丰富的蜂鸣器声学反馈
*   **恒温模式**：首次到达设定温度时长鸣提示。
*   **回流焊模式**：经过“预热 -> 保温 -> 回流 -> 冷却 -> 完成”的每一个阶段都会有不同时长的蜂鸣提示。
*   **UI 交互**：参数确认及报错均有清脆的音效反馈。

#### 5. ⚙️ 全新的人机交互逻辑
*   **操作统一**：全系统支持 **短按确认/修改**，**长按退出/急停**。
*   **运行中调温**：在“恒温加热”过程中，直接旋转旋钮即可进入“编辑预览状态”，红字显示修改预览（如 `目标:150->180C`），短按即可瞬间应用新温度，无需退出重进。

## 硬件配置与引脚定义

*   **MCU**: GD32E230C8T6
*   **加热控制 (SSR)**: PB8
*   **旋钮编码器 (EC11)**: A相(PA1) / B相(PA2) / 按键(PA0)
*   **蜂鸣器 (无源 + S8050驱动)**: PA8 (使用 TIMER0_CH0 产生 PWM)
*   **温度传感器 (MAX6675)** *(使用硬件 SPI0)*:
    *   CS: PB10
    *   SO(MISO): PA6
    *   SCK: PA5
*   **TFT 屏幕 (ST7735)** *(使用硬件 SPI0)*:
    *   CS: PA4
    *   SDA(MOSI): PA7
    *   SCK: PA5
    *   RS/DC: PB0
    *   RES: PB1

> **提示**：屏幕和温度传感器共享 `SPI0` 总线的外设硬件引脚，极大提高了数据传输速率。

## 烧录方式

GD32E230 支持两种烧录方式：

### 方式一：串口 ISP 烧录（推荐，无需调试器）

通过 Type-C 直连，利用芯片内置 bootloader 通过串口烧录。

**BOOT0 跳帽说明：**

| BOOT0 | 模式 | 说明 |
|-------|------|------|
| 0 (GND) | 普通模式 | 从内部 Flash 运行程序 |
| 1 (3.3V) | ISP 模式 | 进入内置 bootloader，等待串口烧录 |

**烧录步骤：**

1.  将 BOOT0 跳帽接到 1 (3.3V)，拔插 Type-C 重新上电。
2.  在 `reflow_plate` 目录下执行 Python 烧录脚本（需要预先安装 pyserial）：
    ```powershell
    python flash_gd32.py COM6
    ```
    *或指定固件路径：* `python flash_gd32.py COM3 .pio/build/gd32e230c8t6/firmware.bin`
3.  **烧录完成后，将 BOOT0 跳帽改回 0 (GND)，拔插 Type-C 重新上电，程序即开始运行。**

### 方式二：GD-Link 调试器烧录

需要连接 GD-Link/ST-Link 调试器到板子 SWD 接口。
```powershell
pio run -e gd32e230c8t6 -t upload
```

### 常见问题 (FAQ)

*   **屏幕不亮或旋钮不跟手**: 检查屏幕和编码器接线顺序是否与 `hw_config.h` 引脚定义一致。
*   **`No response - check BOOT0 and reset`**: 串口刷机时 BOOT0 没接 1 或没重新上电，拔插 Type-C 后重试。
*   **收到 `0x1F` (NACK)**: bootloader 状态异常，彻底断电（拔 Type-C 等 3 秒）后重新上电即可。
